# Faith Gôndolas

Site estático de catálogo. `index.html` está na raiz, sem instalação ou build remoto.

Na Vercel: importe este repositório, selecione Other, raiz `.` e diretório de saída `.`. Não há banco de dados neste site.

Esta pasta é gerada pelo projeto local da Faith. As alterações devem ser feitas nas fontes e no catálogo local; ao concluir `03-Site/fonte/build3.py`, a sincronização cria um commit quando existem diferenças e executa push na branch main.

O repositório contém somente o site público, sem CRM, documentos internos ou credenciais. A URL pública usada no sitemap e nos compartilhamentos é configurada por FAITH_SITE_URL no gerador local e deve corresponder ao domínio definitivo.
